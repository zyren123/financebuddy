# TQQQ Gate：本地回测结果

运行日期：2026-10-14。[策略一手来源核对](tqqq-gate-source.md)，[运行说明](../../backtests/tqqq_gate/README.md)，[本机 HTML 图表报告](../../backtests/tqqq_gate/results/report.html)。生成的行情快照与报告保留在本机，未纳入 Git。

本次独立实现的是三门基础规则及两种防守资产。没有使用作者未公开的完整 Python 回测引擎。ETF 由项目现有 Twelve Data 连接取得 `adjust=all` 日线；指数与短期利率来自 FRED。共同可用区间为 **2010-02-11 至 2026-10-12，4,192 个收盘估值**，虽然请求截至 10 月 13 日，ETF 服务当前只提供到 12 日。

## 真实基金区间

初始 $1，无定投、税前、分红复投。昨日收盘信号在今日收盘执行，新仓从下一交易日承担收益；每次组合切换扣 2.5bp，两次切换完整往返 5bp。期初建仓同样扣费，期末不强制平仓。

| 策略 | 年化收益 | 最大回撤 | Sharpe | 初始 $1 期末值 | TQQQ 持仓时间 | 后续切换次数 |
|---|---:|---:|---:|---:|---:|---:|
| TQQQ / T-bill 计息代理 | 41.03% | -44.78% | 1.03 | $307.81 | 69.6% | 90 |
| TQQQ / TLT | 42.41% | -47.61% | 1.04 | $362.28 | 69.6% | 90 |
| TQQQ 买入持有 | 43.38% | -81.57% | 0.88 | $405.59 | 100% | 0 |
| QQQ 买入持有 | 19.39% | -35.12% | 0.89 | $19.19 | 0% | 0 |

在真实基金存续期，策略降低了账户最大回撤与波动，但其年化收益并未超过 TQQQ 买入持有。TLT 防守相对现金计息代理增加约 1.39 个百分点年化，也使最大回撤加深约 2.83 个百分点。

2022 年尤其能看出防守资产差别：现金版本 +2.03%，TLT 版本 -31.24%，TQQQ 买入持有 -78.98%，QQQ 买入持有 -32.58%。即使门控规则相同，长债也可能在股市下跌时一起下跌。数字来自本机 `annual_returns.csv`，不是白皮书表格的复制。

## 执行时点比小额费用影响更大

| 执行假设（每次切换 2.5bp） | T-bill 版本年化 / 最大回撤 | TLT 版本年化 / 最大回撤 |
|---|---:|---:|
| 当日信号在当日收盘成交（偏乐观） | 44.83% / -38.42% | 46.40% / -39.71% |
| 次日收盘成交（默认） | 41.03% / -44.78% | 42.41% / -47.61% |

第一行等同常见 `signal.shift(1) * close_to_close_return` 写法；该写法让当日收盘之后才能知道的信号在同一个收盘价成交。第二行遵循作者公开 README 的“前一收盘信号，今日收盘行动”执行含义。作者完整回测引擎未公开，所以这是明确分列假设，而非断言作者代码存在前视错误。完整 0/1/2 天收盘延迟、0/2.5/5/10bp 成本的 24 组结果在 `sensitivity.csv`。

默认次日收盘版本从零成本改为每次切换 10bp，现金版本年化由 41.22% 降至约 40.45%；本次时点差异比这段费用差异更显著。

## 与白皮书口径的关系

- 白皮书首页 36.59% 年化是包含 2010 年前合成基金的 1985 起长历史、T-bill 防守版本；与本报告真实 ETF 区间不同。
- 截至白皮书页尾 2026-08-07 的本地真实基金版本：T-bill 年化 40.65% / 回撤 -44.78%，TLT 年化 42.05% / 回撤 -47.61%，TQQQ 持有年化 43.35% / 回撤 -81.57%。作者真实基金段报告基础策略 43.19% 与持有 43.07%，本地没有逐项完全复现；数据供应商、起止日期、交易延迟和现金口径都可能影响差异。
- QQQ 非分红复权价格作信号的额外实跑：现金版本 41.19% 年化，TLT 42.56%。主回测的 NDX 与 QQQ 信号有 38/4,192 日不同（约 99.09% 一致），未复现作者所称 99.98% 一致率。
- 可选长历史代理已单独运行：1986-12-30 至 2026-10-12，现金策略年化 32.96%、最大回撤 -53.40%；合成买入持有年化 13.60%、最大回撤 -99.98%。早期基础是 NDX **价格收益**，缺少指数分红，与作者 QQQ **总收益**重构不同，也缺少 1985 年数据。此代理只能展示跨危机行为，不能称为精确复现。

## 已完成的验证

- 对作者公开 `compute()` 的 169 个可计算日逐一运行真实 JavaScript，与独立 Python 比较信号、短期波动、波动比和滚动回撤，全部一致。
- 七项行为测试通过：双向连续确认、回撤迟滞严格边界、预热、成交之后才开始承担收益、费用时点、未来价格不改过去信号、缺失资产价格拒绝填补。
- 本地 HTML 在浏览器实际加载，两个 SVG 图、结果表及年度收益正常渲染，无外部脚本，页面无横向溢出（表格可横向滚动）。
- 所有 Python 文件编译检查通过；没有改动或重新测试原有前端业务。

现金腿使用 DTB3 的前一交易日贴现率 /100/252 作计息代理，未精确模拟国库券收益率换算、交易或持券滚动。ETF 复权收益已含基金费率。CAGR 按自然日跨度；Sharpe 按 252 交易日并扣现金代理收益。参数来自原文，未进行本地优化，也未模拟税务递延或定投。
