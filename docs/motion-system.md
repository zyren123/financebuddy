# FinanceBuddy motion system

FinanceBuddy 的动效保持原有黑底、铜色细线、直角与数据配色。形变解释数据变化和控件之间的关系。

## 物理参数

`src/motion/spring.ts` 采用单位质量的阻尼弹簧，每个积分子步不超过 1/240 秒。更新目标保留当前位置和速度。每个弹簧仅在运动期间请求帧，页面隐藏时收敛并停止请求帧。

| 用途 | 刚度 | 阻尼 |
| --- | ---: | ---: |
| 按下与释放 | 740 | 48 |
| 选中下划线 | 560 | 43 |
| 曲线、节点、面板、时间轴 | 320 | 35 |

`useSpring` 直接更新 SVG 属性或 DOM 样式，每帧不触发 React 渲染。按钮的 `scale` 独立于其他 `transform`，不会覆盖选中指示器的位置。

## 径向图表

`Detector` 保留同一序列的 SVG 节点。`trackCoordinates` 将圆弧转换为固定拓扑的三次贝塞尔控制点，终点仍由真实 ROC 的绝对值、刻度和符号决定。路径和节点使用同一组插值坐标。单段贝塞尔近似原有 70° 圆弧，终点半径保持精确。

数据变化或管理员修改 ROC 周期时，路径控制点、幽灵径迹和探测环连续更新。标准范围内的六个环槽始终保留，减少环数时收敛到外环并隐藏。动画期间文字给出目标数据，图形在收敛后与目标一致。

节点的外圈与提示面板使用相同的 SVG 路径命令。外圈从圆形扩展为直角面板，背景沿轮廓填入，内容在轮廓接近展开时出现。关闭时反向收敛。提示内容来自当前读数及其日期，手机提示面板按 1.65 倍 SVG 单位绘制。悬停、触屏点按、键盘焦点和 Escape 均可操作。

首屏序列包括探测环绘制、72 根刻度依次出现、径迹绘制、命中节点和数字更新。径迹开始于 120ms，每条间隔 105ms，单条绘制 640ms。没有持续循环动画。

## 导航与控件

`useCoverMorph` 根据滚动进度移动同一个探测器，收起细节并补偿径迹线宽，落点由封面和页头实际位置计算。滚动每帧只写样式，尺寸变化时重新测量。离开封面的控件不再接收键盘焦点。

`SelectionIndicator` 在容器或字体尺寸变化时测量选项，之后通过平移与横向缩放移动下划线。`applyRange` 通过 `timeToIndex` 从日期计算目标范围，再在 lightweight-charts 的逻辑时间范围之间插值，保留原数据。图表的范围设置延迟到绘制时执行，设置后立即读取会返回旧范围，不能用于计算动画终点。鼠标拖动或滚轮操作会中断时间轴动画。

`SettingsReveal` 从卡片设置按钮下方的右上角展开裁切区域。设置打开时底层图表保持挂载。关闭后的表单使用 `inert` 和 `aria-hidden`，不会截获焦点。

## 减少动态效果

系统的 `prefers-reduced-motion` 在运行时生效。弹簧直接更新至目标状态，径迹与刻度直接展示，进入图表与返回封面采用即时滚动。颜色、选中状态和准确读数继续保留。

## 验证入口

`npm run smoke:motion` 对已启动的本地开发服务器运行系统 Chrome 验证。测试使用隔离的合成行情与出厂布局，拒绝布局写请求，不消耗行情配额。`SMOKE_URL` 可指定本地地址，`MOTION_OUT` 可指定截图与 `results.json` 的目录，默认输出到 `/tmp/financebuddy-motion`。

验证覆盖桌面、390×844 触屏、减少动态效果、节点展开与收回、键盘 Escape、共享图表往返、设置保留图表实例、周期变化时路径与节点的一致性，以及快速区间切换。帧间隔采样来自单次本机浏览器运行，只用于发现明显停顿，不代表所有设备上的帧率保证。

`npm run smoke:range-motion` 单独验证真实图表的逐帧逻辑范围与最终日期。`smoke:motion` 同时检查实际卡片画布出现多个中间画面，避免只验证选中下划线而漏掉图表跳变。
